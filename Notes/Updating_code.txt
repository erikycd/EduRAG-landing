# Actualizar cambios en tu sitio desplegado

Cada vez que hagas modificaciones en tu código, sigue estos pasos:

## Flujo de trabajo completo:

### Paso 1: Haz tus cambios en el código

Edita los archivos en src (componentes, estilos, etc.)

### Paso 2: Prueba localmente

```bash
cd landing-react
npm start
```

Verifica que todo funcione correctamente en `http://localhost:3000`

### Paso 3: Despliega a GitHub Pages

```bash
npm run deploy
```

Este comando automáticamente:
- ✅ Ejecuta `npm run build` (genera versión optimizada)
- ✅ Sube los archivos a la rama `gh-pages`
- ✅ Actualiza tu sitio web

### Paso 4: Guarda cambios en tu rama main (Opcional pero recomendado)

1. Transferir cambios a Staged Changes
2. Asigna una etiqueda en el cuadro de texto i.e. v.0.2.0
3. Ejecuta Commit and Push a main

```bash
cd ..
git add .
git commit -m "Descripción de tus cambios"
git push origin main
```

O usa **GitHub Desktop**:
1. Verás los cambios en la pestaña "Changes"
2. Escribe un mensaje de commit
3. Haz clic en "Commit to main"
4. Haz clic en "Push origin"

---

## Resumen del flujo:

```bash
# 1. Edita archivos en landing-react/src/
# 2. Prueba localmente
npm start

# 3. Despliega cuando estés satisfecho
npm run deploy

# 4. (Opcional) Guarda en main
git add .
git commit -m "Actualización de estilos"
git push origin main
```

## 🎨 Mejoras visuales implementadas:

### Animaciones disponibles:
- **fadeInUp, fadeInLeft, fadeInRight**: Animaciones de entrada
- **float-animation**: Efecto flotante continuo
- **pulse-animation**: Efecto de pulso
- **card-hover**: Efecto hover para tarjetas
- **btn-animated**: Botones con efectos
- **icon-bounce**: Iconos con rebote al hacer hover

### Degradados modernos:
- **gradient-primary**: Púrpura a violeta
- **gradient-success**: Verde esmeralda
- **gradient-info**: Azul cielo
- **gradient-sunset**: Rosa a amarillo
- **gradient-ocean**: Azul profundo a cyan

### Efectos especiales:
- **glass-effect**: Efecto glassmorphism
- **text-gradient**: Texto con degradado
- **shimmer**: Efecto de carga brillante
- **scroll-reveal**: Revelar al hacer scroll

### Cómo usar en tus componentes:

```jsx
// Ejemplo de uso en un componente:
import '../styles/animations.css';
import { initScrollAnimations } from '../utils/scrollAnimations';

function MiComponente() {
  useEffect(() => {
    initScrollAnimations();
  }, []);

  return (
    <div className="scroll-reveal fade-in-up">
      <h1 className="text-gradient">Título con degradado</h1>
      <button className="btn-animated gradient-primary">
        Botón animado
      </button>
      <div className="card-hover glass-effect">
        Tarjeta con efecto glass
      </div>
    </div>
  );
}
```

## 📋 Estructura de la página de Equipo:

### Archivos creados:
- `src/data/teamMembers.js` - Datos del equipo
- `src/components/Team/Team.jsx` - Componente principal
- `src/components/Team/TeamCard.jsx` - Tarjeta individual
- `src/components/Team/Team.css` - Estilos del equipo

### Cómo añadir nuevos miembros:

```javascript
// Edita src/data/teamMembers.js
export const teamMembers = [
  // ...existing members...
  {
    id: 3,
    name: "Tu Nombre",
    profession: "Tu Profesión",
    role: "Tu Rol en el Proyecto",
    image: "/images/team/tunombre.jpg",
    linkedin: "URL",
    github: "URL"
  }
];
```

### Integración:
- **Opción 1**: Como sección → Importar `<Team />` en App.jsx
- **Opción 2**: Como página separada → Usar React Router
